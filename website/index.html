WORKFLOW

四步完成一次翻译

无需切换窗口，无需复制粘贴，翻译就在指尖。

1

按下快捷键

任意界面按下 ⌥S，屏幕出现框选遮罩。再次按下 ⌥⇧S 可直接重截上次区域。

2

框选区域

拖动鼠标框选要翻译的屏幕区域，松开即自动识别文字，无需二次点击。

3

查看译文

翻译结果面板自动置顶显示，支持原文/译文/并排三种视图，一键复制或收藏生词。

4

随时调用

应用常驻菜单栏，关窗不退出。看论文、读文档、追字幕，随时唤起。

FEATURES

专注截屏翻译这一件事

砍掉词典、广告、背单词等冗余功能，保留翻译核心体验。

截屏翻译

全局快捷键唤起框选，每屏独立遮罩，实时显示尺寸。松开鼠标即完成 OCR 与翻译。

重截上次区域

字幕、日志、聊天窗口等固定区域，按 ⌥⇧S 一键重截，连续翻译不中断。

原文/译文对照

原图、译文、并排三种视图自由切换。并排模式左右皆为图片，逐句对照更直观。

12 种语言互译

中、英、日、韩、法、德等 12 种语言双向互译，一键交换源/目标语言立即重译。

结果面板置顶

翻译面板常驻屏幕最上层，失焦自动降低透明度。支持拖动、缩放与位置记忆。

生词本

选中文字右键收藏到生词本，支持搜索、删除与 CSV 导出，随时随地复习。

菜单栏驻留

关闭窗口不退出应用，所有功能从菜单栏直达。支持开机自启，也可切换为纯菜单栏模式。

隐私友好

仅需屏幕录制权限。纯离线模式下识别与翻译均在本地完成，数据不出设备。

轻量高效

应用体积约 1MB，纯系统框架构建，零第三方依赖。启动迅速，运行安静。

INSTALL

从源码构建，一分钟完成

需要 macOS 14+ 与 Xcode Command Line Tools。

1

克隆仓库并构建

运行 make-app.sh 脚本，自动编译并打包为 SnapTranslator.app。

2

移动到应用程序

将生成的 .app 复制到 /Applications 目录并打开。

3

授权并开始使用

首次截屏时授予「屏幕录制」权限，然后按 ⌥S 即可开始翻译。

# 克隆仓库 git clone https://github.com/ideshun/SnapTranslator.git cd SnapTranslator # 构建（产物约 1MB） ./make-app.sh # 安装到应用程序目录 cp -R build/SnapTranslator.app /Applications/ open /Applications/SnapTranslator.app

FAQ

常见问题

和付费的屏幕翻译应用有什么区别？

SnapTranslator 专注截屏翻译这一件事，没有词典、广告、背单词等冗余功能。体积约 1MB，开源免费，代码透明可审计。

可以完全离线使用吗？

可以。在设置中开启「仅离线」模式后，应用只使用 Apple 系统翻译，识别与翻译均在本地完成，绝不联网。需要 macOS 15+ 并提前下载语言包。

需要授予哪些系统权限？

仅需「屏幕录制」权限（截屏必需）。无需辅助功能权限，无需网络权限。API Key 安全存储在系统 Keychain 中。

翻译引擎挂了怎么办？

应用内置多引擎自动降级机制。主引擎失败或超时（15 秒）会自动切换到下一个引擎，无需手动干预，保证翻译不中断。

支持哪些语言？

支持中文、英语、日语、韩语、法语、德语、西班牙语、葡萄牙语、俄语、意大利语、繁体中文、越南语等 12 种语言双向互译，源语言自动检测。
